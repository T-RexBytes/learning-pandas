# Pandas Learning Journey

This repository documents my learning journey with Pandas.

## Goals

- Track daily learning progress
- Maintain structured notes
- Store practice code and experiments
- Record important Pandas concepts and examples

## Topics Covered

- Series (creation, custom indexes, loc/iloc, boolean filtering)
- DataFrames (creation, custom index, add columns, append rows, handle NaN)
- Selecting and indexing (columns, rows, slices, label vs integer index)
- Filtering data (boolean masks, combined conditions)
- Importing data (CSV, JSON, file/path handling)
- Aggregation and grouping (mean, min, max, sum, count, groupby)
- Practice with Pokémon datasets
- Practice scripts for each concept (see code folders)
