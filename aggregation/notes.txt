aggregate functions = Reduces a set of values into a single summary value
Used to summarize and analyze data
Often used with the groupby() function


now if we want to aggregate something we will have to pass the aggregate method to the DataFrame
like this : 

df.mean() now this only works with numreic numbers only so it will throw a error as not every value is a number in my df
df.mean(numeric_only=True) by using this we are passing the method to work only with the numeric numbers 
now this will work

like this :
No           75.500000
Height        1.200000
Weight       46.231333
Legendary     0.026667
