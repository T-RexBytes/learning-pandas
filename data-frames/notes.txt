# 4. Using loc() in a DataFrame

now we could also use the loc feature in dataframes too

by using this we could get the information about the specific mentioned index or label from the dataset
upon using it we get some output like this

Name    Robin
Age        20
Name: Emplpyee 1, dtype: object

here we could see that as it was in the data labeled as of name and age it showed up specifically for that index only
and below that we get the custom name that we have given which is Employee 1 and with the datatype of the dataset which is obeject here
as we have passed the specific index through the loc property, which will show as of meta data at the end of the output
